# Salesforce Utilities portfolio site

Static site: `index.html` plus the demo videos and poster images in `media/`. No build step.

## Before you publish
Open `index.html`, search for `CONTACT_EMAIL`, and fill in your email and/or LinkedIn URL.

## Publish on GitHub Pages (free)
1. Create a **public** repository named `KartikNahar.github.io`.
2. Upload everything in this folder (`index.html`, `.nojekyll`, `media/`) to the repository root.
3. In the repository: Settings → Pages → Source: "Deploy from a branch" → `main` / root.
4. The site appears at `https://KartikNahar.github.io` within a few minutes.

Do not upload the Python source of the tools to this repository. It is public.
